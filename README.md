# RTF ↔ MD 変換ツール

RTFとMarkdownをブラウザ内だけで相互変換する静的ウェブアプリです。ファイルはサーバーへ送信されません。

## 使い方

1. `index.html` をダブルクリックしてブラウザで開きます。
2. `.rtf` または `.md` ファイルをドラッグ＆ドロップするか、「ファイルを選択」を押します。
3. 変換結果を確認・編集し、コピーまたはダウンロードします。

## 対応する主な書式

- 見出し
- 太字、斜体、取り消し線
- 箇条書き、番号付きリスト
- 引用
- コード、コードブロック
- リンク
- 日本語などのUnicode文字
- Shift_JISなど、RTF内で指定された主要な文字コード

変換結果欄は「クリア」ボタンで内容だけを消去できます。

複雑な表、埋め込み画像、脚注、ページレイアウトなど、Markdownに直接対応しないRTF機能は簡略化または省略されます。
